# Maze_Escape
Maze Escape
A 2D puzzle-adventure game developed in C++ using the Simple and Fast Multimedia Library (SFML). The player must navigate through a maze, manage collisions, and reach a designated exit point to complete the game.

Features
Dynamic Maze Navigation: Implements smooth player movement with wall collision logic.

Visuals and Audio: Leverages SFML for hardware-accelerated 2D graphics and spatial sound effects.

Win/Loss Logic: Real-time detection of the player's position relative to the goal and obstacles.

Clean Architecture: Organized C++ source code designed for readability and potential expansion.


Compile maze_escape.cpp and link against the following SFML modules:

sfml-graphics

sfml-window

sfml-audio

sfml-system

How to Play
Movement: Use the Arrow Keys to navigate the character.

Objective: Find the path to the exit without colliding with walls or traps.

Restart: Press the circular arrow to reset the level.
